# Barrera's Fitness Client Progress Analysis

## Project Overview
This data analytics capstone project analyzes client exercise compliance and body weight trends for Barrera's Fitness. The goal of the analysis is to identify patterns in client consistency and progress that can help support coaching decisions and improve client outcomes. 

## Tools Used
- Excel - data organization and cleaning
- BigQuery / SQL - data analysis
- GitHub - project documentation and portfolio presentation
- 
## Analysis 
The analysis focuses on:
- Average exercise compliance by month
- Average body weight by month
- Weight changes by client
- Average exercise compliance by client
- Overall body weight trends

## Key Findings
- Exercise compliance varied across clients and across the three-month period.
- Body weight changed over time, showing measurable client progress.
- Comparing compliance and weight trends helped identify differences in client consistency and outcomes.
